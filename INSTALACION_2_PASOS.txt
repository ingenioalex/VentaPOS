1️⃣  Copia los 2 archivos a:

2️⃣  Haz DOBLE CLICK en:
    INSTALAR-SECCIONK.bat

3️⃣  Espera 2 minutos mientras se instala...

4️⃣  ¡Listo! 🎉

────────────────────────────────────────────────────────────────────────────

🎯 ¿QUÉ HACE EL INSTALADOR?
────────────────────────────────────────────────────────────────────────────

✅ Descarga todos los archivos de SeccionK desde GitHub
✅ Los copia a las carpetas correctas de tu proyecto
✅ Modifica bootstrap/app.php (agrega rutas)
✅ Modifica config/auth.php (agrega guard)
✅ Ejecuta migraciones (crea tablas seccionk_*)
✅ Carga datos de prueba
✅ Limpia y regenera caché


📂 ARCHIVOS QUE SE CREAN
────────────────────────────────────────────────────────────────────────────

app/Http/Controllers/SeccionK/     ← Controladores
app/Models/SeccionK*.php           ← Modelos
app/Http/Middleware/SeccionKAuth.php ← Autenticación
resources/views/seccionk/          ← Vistas
routes/seccionk.php                ← Rutas
database/migrations/2026_10_11_... ← Migración
database/seeders/SeccionKSeeder.php ← Datos de prueba


⚠️ IMPORTANTE
────────────────────────────────────────────────────────────────────────────

✅ SeccionK usa su PROPIA base de datos (tablas seccionk_*)
✅ NO afecta a VentaPOS en absoluto
✅ Funciona como un MÓDULO INDEPENDIENTE
✅ Se ejecuta en la misma aplicación Laravel


🔧 SI ALGO SALE MAL
────────────────────────────────────────────────────────────────────────────

Ejecuta estos comandos en tu terminal:

  php artisan config:clear
  php artisan route:clear
  php artisan migrate
  php artisan db:seed --class=SeccionKSeeder
