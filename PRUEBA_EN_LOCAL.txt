📋 OPCIÓN 1: WINDOWS CON LARAGON (MÁS FÁCIL)
────────────────────────────────────────────────────────────────────────────

Si tienes Windows, esta es la forma más fácil:

1️⃣  Descargar e instalar Laragon Full:
    👉 https://laragon.org/download/
    
    ✅ Incluye PHP, MySQL, Node.js automáticamente
    ✅ Un solo instalador
    ✅ No requiere configuración

2️⃣  Después de instalar Laragon:
    - Abre Laragon
    - Click en "Terminal" (botón en Laragon)

3️⃣  En la terminal de Laragon, ejecuta:

    cd C:\laragon\www
    git clone https://github.com/ingenioalex/VentaPOS.git seccionk
    cd seccionk
    git checkout cursor/seccionk-module-0c7c
    INICIAR-SERVIDOR.bat

4️⃣  ¡Listo! Se abre automáticamente en tu navegador.


📋 OPCIÓN 2: CUALQUIER SISTEMA (MANUAL)
────────────────────────────────────────────────────────────────────────────

Si ya tienes PHP y Composer instalados:

1️⃣  Clonar el repositorio:

    git clone https://github.com/ingenioalex/VentaPOS.git
    cd VentaPOS
    git checkout cursor/seccionk-module-0c7c

2️⃣  Ejecutar el script de instalación:

    ┌─ Windows ──────────────────┐
    │ setup-local.bat            │
    └────────────────────────────┘

    ┌─ Linux/Mac ────────────────┐
    │ chmod +x setup-local.sh    │
    │ ./setup-local.sh           │
    └────────────────────────────┘

3️⃣  Iniciar el servidor:

    ┌─ Windows ──────────────────┐
    │ INICIAR-SERVIDOR.bat       │
    └────────────────────────────┘

    ┌─ Linux/Mac ────────────────┐
    │ chmod +x iniciar-servidor.sh│
    │ ./iniciar-servidor.sh      │
    └────────────────────────────┘

    O manualmente:
    
    php artisan serve

🔧 COMANDOS ÚTILES
────────────────────────────────────────────────────────────────────────────

Ver todas las rutas de SeccionK:
  php artisan route:list --path=seccionk

Resetear base de datos (borrar todo y empezar de nuevo):
  php artisan migrate:fresh --seed

Ver logs en tiempo real:
  tail -f storage/logs/laravel.log     (Linux/Mac)
  Get-Content storage/logs/laravel.log -Wait    (Windows PowerShell)

Limpiar caché:
  php artisan config:clear
  php artisan route:clear
  php artisan view:clear


🐛 SI ALGO NO FUNCIONA
────────────────────────────────────────────────────────────────────────────

ERROR: "php: command not found"
  👉 PHP no está instalado o no está en PATH
  👉 Solución: Instala Laragon (Windows) o PHP manualmente

ERROR: "composer: command not found"
  👉 Composer no está instalado
  👉 Solución: https://getcomposer.org/download/

ERROR: "Class not found"
  👉 Ejecuta: composer dump-autoload

ERROR: "Database not found"
  👉 Ejecuta: touch database/database.sqlite (Linux/Mac)
  👉 O: type nul > database\database.sqlite (Windows)
  👉 Luego: php artisan migrate

ERROR: "Route not found"
  👉 Ejecuta: php artisan route:clear
  👉 Ejecuta: php artisan config:clear

ERROR: Puerto 8000 ocupado
  👉 Usa otro puerto: php artisan serve --port=8080
  👉 Abre: http://localhost:8080/seccionk


📱 PROBAR EN TU CELULAR
────────────────────────────────────────────────────────────────────────────

1️⃣  Encuentra tu IP local:

    Windows:
      ipconfig
      (busca "Dirección IPv4", ejemplo: 192.168.1.100)
    
    Linux/Mac:
      ifconfig
      (busca "inet", ejemplo: 192.168.1.100)

2️⃣  Inicia el servidor en todas las interfaces:

    php artisan serve --host=0.0.0.0

3️⃣  En tu celular (conectado a la misma red WiFi), abre:

    http://TU_IP:8000/seccionk
    
    Ejemplo: http://192.168.1.100:8000/seccionk
